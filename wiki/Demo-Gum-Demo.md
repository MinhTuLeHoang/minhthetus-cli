# Gum Interaction Demo (Developer Debug Tool)

> [!NOTE]
> This command is intended for development and debugging purposes. It is compiled under the `dev` tag and available via `minhthetus-cli debug tui-demo`.

Demonstrates the enhanced UI capabilities provided by Charmbracelet Bubble Tea / Lipgloss natively.

## Usage
```bash
minhthetus-cli debug tui-demo
```

## Options

*   `-h, --help`: Show the help message and exit.

## Flow

1.  **Run Demo**:
    *   Demonstrates stylized headers, borders, colors, and padding.
    *   Runs interactive TUI selection lists.
    *   Displays native multi-line text input fields.
    *   Shows TUI activity spinners for background tasks.
    *   Prints custom colors and symbols for status reporting.
