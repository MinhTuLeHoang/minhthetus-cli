# Configuration Directory (`~/.minhthetus-cli/`)

The `~/.minhthetus-cli/` directory serves as the local configuration and support hub for the `minhthetus-cli`. It stores persistent data, shell integration scripts, and autocompletion logic to provide a seamless experience across different terminal sessions.

## Directory Overview

This hidden directory is automatically created in your home folder when you first run certain `minhthetus-cli` commands or during the initial setup.

## Files and Their Purposes

### 1. `git-accounts.json`
- **File Type**: `JSON`
- **Data Interface**:
  ```typescript
  interface GitAccount {
    title: string; // Display name for the account (e.g., "Work", "Personal")
    name: string;  // Git user.name
    email: string; // Git user.email
  }

  type data = GitAccount[];
  ```
- **Purpose**: Stores a list of Git identities (titles, names, and emails).
- **Supported CLI**: `minhthetus-cli git account`
- **Functionality**: 
  - Allows you to save multiple Git profiles (e.g., Work and Personal).
  - Enables quick switching of Git identity for the current repository.
  - Managed via the `--manage` flag: `minhthetus-cli git account --manage`.

### 2. `list-repo.json`
- **File Type**: `JSON`
- **Data Interface**:
  ```typescript
  interface RepoConfig {
    name: string;        // Name of the repository
    description: string; // Description from package.json
    path: string;        // Absolute path to the repository
  }

  type data = RepoConfig[];
  ```
- **Purpose**: Tracks local repositories for bulk operations.
- **Supported CLI**: `minhthetus-cli web check-malware`, `minhthetus-cli git list-repo`, `minhthetus-cli repo-untrack <path>`
- **Functionality**:
  - Stores metadata and paths for projects registered with the CLI.
  - Used for scanning multiple local projects for vulnerable or malicious packages.
  - Interactive management via the `git list-repo` command.
  - Automatically cleaned up if paths are found to be invalid during a scan.

### 3. `shell-wrapper.sh`
- **File Type**: `Shell Script`
- **Interface/Behavior**:
  - Modifies the current shell session by sourcing a temporary file generated by the CLI.
  - Intercepts calls to the `minhthetus-cli` command.
  - Environment Dependency: Uses `MINHTHETUS_SHELL_PIPE`.
- **Purpose**: A shell function wrapper that intercepts `minhthetus-cli` calls (used by legacy/dev environment-switching flows).
- **Supported CLI**: Specifically supports environment-modifying flows such as `debug switch-node`.
- **Functionality**:
  - The CLI normally runs in a subshell, meaning it cannot change the environment of your primary terminal (like changing directories or switching Node versions).
  - This wrapper captures specific shell commands emitted by the CLI into a temporary file and "sources" them in your current session.

### 4. `aliases.json`
- **File Type**: `JSON`
- **Data Interface**:
  ```typescript
  interface AliasEntry {
    name: string;   // Alias name (e.g., "master", "pull", "c")
    command: string; // Shell command to execute
    kind?: string;  // Optional preset identifier (e.g., "preset:master")
  }

  interface AliasConfig {
    aliases: AliasEntry[];
    applied_suggestions: string[]; // Sticky IDs of applied built-in suggestions
  }
  ```
- **Purpose**: Stores user-managed shell command aliases and tracks applied built-in suggestions.
- **Supported CLI**: `minhthetus-cli sys alias`
- **Functionality**:
  - Persists managed aliases as the single source of truth for cross-shell synchronization.
  - Tracks applied suggestions (`master`, `pull`, `c`) so selected suggestions do not reappear on subsequent runs.
  - Synchronized into delimited `# >>> minhthetus-cli aliases >>>` ... `# <<< minhthetus-cli aliases <<<` blocks across `~/.zshrc`, `~/.bashrc`, `~/.bash_profile`, and Windows PowerShell (`5.1` and `7+`) profiles.

## Shell Completion Profiles (Managed Outside `~/.minhthetus-cli/`)

Rather than generating static `completion.zsh`/`completion.bash` files inside `~/.minhthetus-cli/`, `minhthetus-cli setup-completion` installs dynamic Cobra completion hooks directly into your shell's native profile/completion files (delimited by `# >>> minhthetus-cli completion >>>` and `# <<< minhthetus-cli completion <<<`) and `minhthetus-cli uninstall` cleans them up cleanly:

- **PowerShell 7+ (Windows)**: `<Documents>\PowerShell\Microsoft.PowerShell_profile.ps1` (resolving `Documents` via the Windows Registry `User Shell Folders\Personal`, including OneDrive-redirected paths)
- **Windows PowerShell 5.1**: `<Documents>\WindowsPowerShell\Microsoft.PowerShell_profile.ps1`
- **PowerShell 7+ (macOS / Linux)**: `~/.config/powershell/Microsoft.PowerShell_profile.ps1`
- **Bash / Git Bash**: `~/.bashrc` (and `~/.bash_profile` on Windows Git Bash login shells when needed)
- **Zsh**: `~/.zshrc`
- **Fish**: `~/.config/fish/completions/minhthetus-cli.fish` (respecting `$XDG_CONFIG_HOME`)

## Technical Details

- **Creation**: The directory, config files, and shell integrations are managed by the Go implementation:
  - **cmd/setup_completion.go**, **cmd/completion_windows.go**, **cmd/completion_other.go**: Manage fast cross-platform shell detection, `--shell` overrides, and RC/profile completion hooks.
  - **cmd/uninstall.go**: Performs block-aware cleanup of shell completion hooks and binary removal.
  - **cmd/sys/alias.go** & **cmd/sys/alias_shell.go**: Manage `aliases.json` persistence and cross-shell profile synchronization.
  - **internal/config/**: Manages `~/.minhthetus-cli/` JSON configuration files.
  - **internal/git/**: Handles Git account and repository tracking logic.
- **Permissions**: Configuration files are stored with restricted permissions to protect sensitive information.
